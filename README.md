# Taschenrechner-C

## Beschreibung
Ein Konsolen-Taschenrechner in der Programmiersprache C. 
Mein erstes Projekt während der Vorbereitung auf die Ausbildung 
zur Fachinformatikerin für Anwendungsentwicklung.

## Funktionen
- **Grundrechenarten:** Addition, Subtraktion, Multiplikation, Division
- **Kontrollstruktur:** Verwendung von `switch-case` zur Auswahl der Operation
- **Fehlerbehandlung:** Prüfung auf Division durch Null
- **Benutzereingabe:** Interaktive Eingabe über die Konsole

## Verwendete Technologien
- **Sprache:** C
- **Compiler:** GCC
- **Entwicklungsumgebung:** Cxxdroid

## Kompilieren und Ausführen
```bash
gcc rechner.c -o rechner
./rechner
